# نورالدين للزراعة | Nouradine Agriculture

تطبيق Android أصلي باستخدام Kotlin وJetpack Compose، بواجهة عربية من اليمين إلى اليسار.

## الميزات التي أصبحت موجودة في النسخة التطويرية
- واجهة رئيسية وروابط للأقسام الزراعية.
- مساعد إرشادي محلي أولي، مع إدخال صوتي عبر خدمة التعرف على الكلام في الجهاز، وقراءة الإجابة بصوت Android TTS.
- اختيار صورة من الهاتف لمعاينة صورة النبات قبل التشخيص.
- موسوعة أولية لمحاصيل القمح والطماطم والبطاطا والزيتون والنخيل والفلفل.
- إرشادات أولية عن أنواع التربة وتحليلها.
- إرشادات سلامة الأسمدة والمبيدات دون تخمين جرعات خطرة.
- حاسبة حجم مياه الري النظرية: هكتار × ملم × 10.
- جلب الطقس الحالي عبر Open-Meteo بإحداثيات يكتبها المستخدم.
- إعداد الترحيب الصوتي.
- عرض إعدادات اللغة والملف الشخصي والصورة.
- عرض مواصفات الاشتراك: تجربة 30 يوماً، 8 دولارات لكل دورة شهرين، وتحديث دوري كل شهرين.
- تأجيل أي عملة داخلية إلى مرحلة لاحقة بعد انتشار التطبيق ونجاحه.

## ميزات تحتاج إلى تكامل خارجي قبل اعتبارها جاهزة
- المساعد الذكي المتصل بالإنترنت: أُضيفت واجهة محادثة Android متصلة بخادم Responses API، وأُضيف خادم Node.js يحفظ مفتاح المزود في متغير بيئة على الخادم ويدعم متابعة سياق المحادثة. **لا يعمل الاتصال الحي حتى نشر backend وضبط OPENAI_API_KEY وOPENAI_MODEL على منصة الاستضافة، ثم إضافة متغير المستودع NOURADINE_API_BASE_URL بعنوان HTTPS الأساسي في GitHub Actions وإعادة البناء.** لا تضع المفتاح داخل التطبيق أو GitHub.
- تحليل الصور: نقطة API الخلفية تقبل صورة JPEG/PNG/WebP، لكن رفع الصورة من واجهة التطبيق وربطها بالمحادثة لم يُنجز بعد، ويلزم تقييم الدقة الزراعية قبل الاعتماد على النتائج.
- توقعات الطقس والتنبيهات الزراعية والموقع التلقائي: تحتاج إلى صلاحيات موقع واختبارات وإعداد قواعد التنبيه.
- الترجمة الكاملة للفرنسية والإنجليزية: تحتاج إلى توطين جميع النصوص ومراجعة الترجمة.
- حفظ صورة المالك والخلفية ومزامنتها: يحتاج إلى تخزين دائم آمن وحساب مالك.
- تعريف المتصل: يحتاج مزود بيانات مرخصاً وصلاحيات Android وسياسة خصوصية وموافقة المستخدم.
- الاشتراكات والتحصيل: تحتاج بوابة دفع تدعم بلد صاحب التطبيق، وخادم تحقق من الاشتراكات وإدارة الفواتير والإلغاء.
- لوحة تحكم المالك: يجب تنفيذها بخادم وتوثيق آمن؛ لا تضع صلاحيات الإدارة أو أسرار الخدمات داخل APK.

## تشغيل خادم الذكاء الاصطناعي
راجع `backend/README.md`. يتطلب Node.js 20+، ونشر الخادم خلف HTTPS، وضبط سر `OPENAI_API_KEY` في منصة الاستضافة. النموذج قابل للضبط عبر `OPENAI_MODEL`. يجب إضافة متغير GitHub Actions باسم `NOURADINE_API_BASE_URL` ليُضمّن عنوان الخادم العام في بناء التطبيق. لا يوجد عنوان استضافة مهيأ في المستودع حالياً، لذلك سيظهر التطبيق حالة أن المساعد غير موصول إلى حين إتمام هذه الخطوات.

## البناء السحابي
يستخدم سير GitHub Actions الموجود في `.github/workflows/android-apk.yml` لبناء APK تجريبي وحفظه كـ Artifact. لا تُعتبر عملية البناء وحدها اختباراً شاملاً على الأجهزة؛ يلزم تثبيت التطبيق واختبار الوظائف على أجهزة فعلية.

## الأمان والدقة الزراعية
- لا تحفظ مفاتيح API أو كلمات المرور أو بيانات الدفع في المستودع أو التطبيق.
- جرعات الأسمدة والمبيدات يجب أن تستند إلى تحليل التربة وملصق المنتج المسجل محلياً وإرشاد مختص.
- بيانات الطقس ليست بديلاً عن تنبيهات الجهات الرسمية.
- هذه نسخة تطويرية وليست إصداراً إنتاجياً مكتملاً.
