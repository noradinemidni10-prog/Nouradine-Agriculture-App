# نورالدين للزراعة | Nouradine Agriculture

مشروع Android أصلي باستخدام Kotlin وJetpack Compose.

## ما الموجود في هذه النسخة
- واجهة عربية RTL.
- شاشة رئيسية وبطاقات للأقسام الزراعية.
- بحث محلي عن الخدمات.
- صفحات تعريفية لكل قسم.
- إعداد أولي للبناء السحابي عبر Codemagic.

## ما لم يُفعّل بعد
المساعد الذكي، تشخيص الصور، الطقس المباشر، خدمات الصوت، الدفع والاشتراكات، ومزايا تعريف المتصل. هذه تحتاج إلى خدمات خلفية ومفاتيح API ومزودين مناسبين واختبارات. لا تضع مفاتيح API أو كلمات مرور داخل التطبيق أو مستودع GitHub.

## البناء
يتطلب Android SDK وJDK 17 وGradle Wrapper. من بيئة Android مناسبة شغّل:

```bash
./gradlew assembleDebug
```

ينتج APK التجريبي في `app/build/outputs/apk/debug/`.

## ملاحظة
هذه نسخة برمجية تأسيسية وليست إصداراً إنتاجياً؛ يجب تنفيذ اختبارات البناء والتثبيت والأمان وإكمال الخدمات قبل النشر.
